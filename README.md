# myMidiPlayer
## !! NOT AN ACTUAL MIDI PLAYER !!
this is a procedural MIDI generator, which really isn't too much of a song

this was ORIGINALLY planned to be a MIDI player, but I just didn't do it..

## Building

this was made for Visual Studio 2022, so it can be built there.
if you don't have it, you can use `msbuild`, which is included in "Build Tools for Visual Studio 2022".
